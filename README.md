# App de la ACG Rosalía de Castro

Versión web (iPhone) de la app de la Asociación Cultural Galega Rosalía de Castro: calendario de actividades, avisos con notificaciones y documentos.

**Para instalarla en el iPhone:** abre https://acgrosaliadecastro-prog.github.io/ en Safari → botón Compartir → «Añadir a pantalla de inicio».
